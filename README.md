# Bear and Breakfast 한국어 패치 — 곰과 아침식사 v0.1.1

![곰과 아침식사 한국어 로고](resources/image_localization/logo_ko_preview.png)

Windows Steam판 **Bear and Breakfast**의 비공식 한국어 패치입니다. 게임 언어의 **English** 슬롯을 한국어로 바꿉니다.

[v0.1.1 다운로드](https://github.com/munument1/Bear-and-Breakfast-KR/releases/tag/v0.1.1) · [오류 제보](https://github.com/munument1/Bear-and-Breakfast-KR/issues)

## 포함 내용

- 대사, 선택지, 아이템, 메뉴, 퀘스트 등 텍스트 8,725개 항목
- 인물 46명의 이름 및 퀘스트 218개의 표시 문구
- 한국어 타이틀 로고
- 한글 폰트 표시와 기존 저장 파일에 남은 영문 퀘스트 문구 수정
- 원본 백업 및 원복 기능

AI를 활용한 번역 초안과 문맥·말투 검수를 거쳤습니다. 타이틀 로고도 AI 생성 이미지를 사용했습니다. 초기 공개판으로, 전체 플레이 구간에 대한 실기 검수가 끝난 버전은 아닙니다. 오역이나 화면 넘침이 남아 있을 수 있습니다. 타이틀 로고 외 이미지 전체의 한글화를 포함하지는 않습니다.

## 지원 환경

- Windows 64비트, Steam판. 확인한 Steam 빌드 ID: **20292966**.
- Windows 기본 폰트 **맑은 고딕** 필요.
- 원본 게임 파일의 SHA-256이 일치할 때만 설치합니다. 다른 빌드, 다른 상점 버전, 동일 파일을 변경하는 모드와는 호환이 확인되지 않았습니다.
- Python이나 BepInEx를 별도로 설치할 필요가 없습니다.
- 설치 중 임시 파일과 백업용 여유 공간 약 2GB를 권장합니다.

## 설치

v0.1에서 `No known saved quest table was found` 오류가 발생했다면 v0.1.1 설치 프로그램으로 다시 설치하세요. 세이브를 삭제할 필요가 없습니다. 퀘스트 캐시가 없는 세이브는 그대로 보존합니다.

1. 게임을 완전히 종료합니다.
2. Releases에서 **BearAndBreakfast-KR-v0.1.1.zip**을 다운로드하고 압축을 풉니다. GitHub의 자동 생성 `Source code` 파일은 일반 사용자용 설치 파일이 아닙니다.
3. `BearAndBreakfast-KR-v0.1.1.exe`를 실행합니다. `BearAndBreakfast.exe`가 있는 게임 폴더를 선택합니다. 설치 파일을 게임 폴더에 두면 자동으로 경로를 찾습니다.
4. 콘솔 메뉴에서 **1: 설치**를 선택하고 완료 메시지를 기다립니다. PC에 따라 수 분 걸릴 수 있습니다.
5. 직접 게임을 실행하고 언어를 **English**로 선택합니다.

Steam에서 게임을 우클릭한 뒤 관리 → 로컬 파일 탐색으로 게임 폴더를 찾을 수 있습니다. 설치 프로그램은 게임을 실행하거나 Steam에 로그인하지 않습니다.

설치 기록과 원본 백업은 게임 폴더의 `.BearAndBreakfast-KR`에 보관합니다. 원복에 필요하므로 삭제하지 마세요. 기존 저장 파일을 수정할 때도 원본을 백업합니다. 저장 파일은 표시 문구만 변경하며 진행 상태는 유지합니다. 과거 롤백 저장본을 불러와 영문 퀘스트가 다시 나타나면 설치 프로그램의 **1: 설치**를 다시 선택해 주세요.

## 제거 / 원복

게임을 종료한 뒤 같은 설치 프로그램에서 **2: 원복**을 선택합니다. 현재 게임 진행 상황을 유지하며 게임 파일과 저장된 퀘스트 표시 문구를 원본으로 되돌립니다. 설치 이후 Steam 업데이트나 다른 모드로 파일이 변경되면 자동 원복을 중단합니다. 이 경우 Steam의 설치된 파일 → 무결성 검사로 게임 파일을 복원할 수 있습니다. Steam 무결성 검사만으로 저장 파일의 표시 문구가 바뀌지는 않습니다.

## 오류 제보

[Issues](https://github.com/munument1/Bear-and-Breakfast-KR/issues)에 스크린샷, 인물/퀘스트 이름, 발생 위치, 패치 버전과 Steam 빌드 ID를 알려 주세요. 설치 실패 시 `.BearAndBreakfast-KR/installer_날짜.log`도 참고할 수 있습니다. 로그를 공개하기 전 개인 경로가 포함되어 있는지 확인해 주세요.

## 검증 범위

원본 대비 텍스트 8,725개 항목과 내부 식별자·대화 링크·분기를 대조했습니다. 인물 이름 조회 46개, 퀘스트 문구 710개 및 기존 저장 파일의 퀘스트 문구 653개를 별도로 확인했습니다. 배포 설치 프로그램은 원본 파일과 저장 파일의 복사본에서 설치 및 원복을 시험합니다. 모든 구간을 실제 플레이한 결과를 뜻하지는 않습니다.

## 소스에서 실행

Python 3.14 환경에서 `pip install -r requirements.txt` 후 `python installer.py --game "게임 폴더" --mode install`로 실행합니다. 원복은 `--mode restore`입니다. 실행 파일 빌드는 `build.ps1`을 사용합니다.

게임 원본 파일·개인 저장 파일·Windows 폰트 파일은 배포하지 않습니다. 설치 시 사용자 PC에 있는 게임과 맑은 고딕을 사용해 패치 파일을 생성합니다. 원작 게임과 상표, 그래픽의 권리는 각 권리자에게 있으며 이 패치는 공식 제작물이나 공식 한국어 지원이 아닙니다.
